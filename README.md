# sport-report · 运动周报

从 `D:\运动记录\index.html` 的记录长出来的第一个 AI 小项目。
**当前阶段：0（只统计，还没有接模型）**

## 用法

1. 打开 `D:\运动记录\index.html`，点「导出 JSON」，得到 `运动记录-2026-10-21.json`
2. 在命令行里跑：

```bash
python stats.py 运动记录-2026-10-21.json          # 本周
python stats.py 运动记录-2026-10-21.json --week 43  # 第 43 周
python stats.py 运动记录-2026-10-21.json --all      # 全部
python stats.py 运动记录-2026-10-21.json --json     # 给下一步喂模型
```

导出文件放在这个目录里就行，`.gitignore` 已经忽略 `*.json`，记录不会被推到 GitHub。

`sample.json` 是编的示例数据（8 条，跨两周），用来测试和演示，随便删。

## 输出长什么样

```
运动记录 · 2026-W43
统计区间 2026-10-19 ~ 2026-10-25
==============================================
总时长              261 分钟（4 小时 21 分）
记录次数            7 次

日均（按运动日）    52.2 分钟
连续天数            3 天
最长一次            65 分钟（骑行，2026-10-23）
```

## 代码结构

| 函数 | 职责 | 为什么单独拆出来 |
|---|---|---|
| `load_records` | 读文件、去重 | 以后可能要读多个导出文件 |
| `compute` | 全部统计 | 纯函数，输入记录输出数字，好测试 |
| `render_text` | 排版成人看的 | 界面和计算分离，以后可换 HTML/PPT |
| `main` | 命令行入口 | 只做参数解析和调度 |
